# webgallery

Tools for preparing photos and generating HTML to display a gallery of images on Rosie the Dog's website.

## About this project

### Use of AI

One of my goals in this project is to learn to write Go code, so I started without AI. I relied on the [Go documentation](https://go.dev/doc/) and [Go by Example](https://gobyexample.com), though it didn't take long before I started discussing design decisions with ChatGPT. I continued to do all the coding manually, with gpt-5.5's input, until I felt like I couldn't learn that much more from doing the coding in this project myself, about three weeks after I started.

At that point, I let an agent take over the coding, first gpt-5.5 and later gpt-5.6-sol.
